## 四、环境警告（**这一轮的头等事**）

**沙箱在 v1.19.2 那一轮中途收回了项目根目录的读权限**，至今未恢复：

- `ls` 项目根、`public/`、`.github/`、`node_modules/` 一律 `Operation not permitted`
- `npm` / `git` 在项目内启动会因 `getcwd` 失败而死
- **绕法**（当前在用）：
  - 测试：在 `/private/tmp/golrun` 建符号链接（`src` `tests` `docs` `index.html` `package.json`），
    三个读不到的夹具用 `git show HEAD:<路径>` 取出来放进去（git 报告这三条路径工作树干净，
    所以字节与原文件相同），再 `jsc -m tests/run-jsc.js`
  - 提交：`git --git-dir=<repo>/.git --work-tree=<repo> …`，在 `/private/tmp` 下执行
  - 编辑：python 脚本 + 绝对路径（Read/Write 工具对 `src/` `tests/` `docs/` 仍可用）
- **Vitest 跑不了**（`node_modules` 读不到）。项目规矩是"两个运行器都要绿"，
  现在**只满足一半** —— 报数时必须说明，不许含糊
- **不要在这个环境里做撤销那一批**（作者明令）：它要动引擎、动栈、动六个写盘入口

## 五、撤销 / 后悔药：方案定稿（等环境恢复后照此开工）

- **范围**：橡皮擦、画笔、清空、随机填充、改尺寸、载入图案、载入内置局、读档
- **多步**，按**字节**封顶 **32 MiB**，超了丢最旧的（一步在橡皮擦场景下等于没有）
- **混合结构**：局部改动存补丁（`input.js` 里 D67 那套 `{cells:[[x,y,旧值]], runDirtyBefore}`
  已经现成，收笔时压栈即可）；整盘改动存 `captureSession` 整份快照
- **实测代价**：2304² 一份 5.06 MiB / 拷贝 1.1ms；1024² 1.00 MiB / 0.2ms；200² 39 KB；
  一笔涂抹约 270 条 ≈ 2 KB
- **补丁自带前提**（主判据）：记下 `w/h/规则记号/世代戳`，对不上就**先说再丢**其余栈，
  绝不按错坐标回滚。世代戳打在**闸那一处**（`assertBoardUnlocked`），
  于是将来新增的写盘路径自动被覆盖
- **兜底**：A 类（改尺寸/读档/载入）压栈即作废之前的补丁（保留，作为第二道）
- **"跑一代作废整栈"是另一处**：`engine.step()` **不过闸**（热路径不为一致性买单），
  所以它有自己的守卫；表旁边要留一行注释说明这件事
- **`canUndo()` 单一判断源**：按钮 `disabled`、临时条出不出现、撤销入口，三处都问它；
  守卫钉住 `disabled` 的赋值表达式就是 `!canUndo()`（§12 第一次落在布尔值上）
- **两个入口一次撤销**：常驻按钮（控制排，`class="rescue"` 救援蓝，手机上四颗各 88px）
  + 清空/随机之后画布下沿的临时条（44px，8 秒）。**同一个 token，消费一次两处都消失**
- **进下半张表**：`{ name: 'undo', writes: 'cells+env+view', keeps: 'replace', asks: false }`
- **还原要连** `currentShowId`（否则 `id=` 指错）**和"在不在跑"**
- **撤销自己不压栈**（守卫钉住）
- 兜底那句话要**具体**：「换了棋盘尺寸之后，之前的改动就退不回去了」，
  三种失效原因共用一个模板；不挡路，但必须有

## 六、冷启动七条（踩过坑才写下来的）

1. **推了才算交付。** 真机复验前先 `curl 线上页面 | grep app-version` 对版本号（D92）。
2. **验分支要照抄用户的复现步骤。** 他说"空盘直接点"，就不许先点随机填充（D105）。
3. **守卫写完必须红一次**，而且**匹配式必须唯一命中**（D110 §30）——
   四次假守卫里三次是"匹到了别的东西"。定位一律走 `locate()`，命中数不对就红。
4. **验收打勾要在 commit 之前单独确认。**
5. **验按时间触发的东西，要用它在生产里真正收到的那个时钟**（D110 §26，差的是量纲）。
6. **时序冷启动：在"还没就绪"的那一刻验**（D110 §5）。
7. **数要量，不要猜**（D82）。

**"验的不是同一情形"这一族已经七个成员**：
不是同一版（D92）/ 不是同一条路（D105）/ 不是同一种人（D107）/ 不是同一个时刻（D110 §5）/
不是同一个会话阶段（§10）/ 不是同一个量纲（§26）/ **不是同一个工作环境**（v1.19.2 那次
在降级沙箱里推的线上，作者点名要记）。
